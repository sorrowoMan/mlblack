# 城市交通时序动力学前瞻预测与零假设风险边界估计（Forecasting & UQ 引擎）

本模块是整套白盒演化管线的**“全知全能的下半场”——实战预测与预警** 环节。
在上一阶段（Nowcasting 代理模型自验）证明了本框架极具洞察的拓扑捕捉能力（解构出 20.8% 的物理相变高墙）后，本组件的使命是：**抛弃“上帝视角”的同日数据协导，直面未知的明天，完成从“代数描述 (Description)”到“严格前瞻 (Strict Forecasting) 与 风险兜底 (Risk Bounding)”的跨越**。

---

## 1. 核心定位：拒绝作弊的“时光倒流”

在绝大多数机器学习甚至时序建模比赛中，参赛者常常会有意无意地混入“数据穿越”（Data Leakage）。通过传入同日的 `flow`, `speed`, `occ`，其预测常常沦为“今天算今天”的数字游戏。
本模块强制开启了 `--drop-same-day-flow-speed-occ 1` 和外部无前瞻环境。引擎**只能使用纯粹的时间状态记忆（Lag 1/2/3 延迟项）和气象等时空外部协变量**，硬碰硬地去推演明天、后天的交通演化。

## 2. 面向前瞻预测（Forecasting）的三大范式跃迁

相对于使用 XGBoost 或 LSTM 等黑盒模型进行时序打榜，本套多目标白盒符号演化框架展现出了碾压级的理论优越性：

### 🧬 1. 时序动力学的显式代数重构（Takens' Embedding in Algebra）
深度学习处理时序总是依赖深层网络的黑盒隐藏记忆，而本模型把昨日、前日的历史状态抽丝剥茧，自发组合出了令人惊叹的自回归代数动力学方程。
以参数寻优的一组真实非线性代理解为例：
$$ \hat{y} = \beta_0 + 2.67 \cos(\text{wind}) + 0.68 \text{ci\_lag}_1 + 0.14 \text{ci\_lag}_3 - 2.01 \log(1 + |\text{speed\_lag}_3|) + \dots $$
* **业务解释性与降维打击**：机器极其聪明地利用了 `ci_lag1` (昨日拥堵) 作为核心的马尔可夫记忆主干，同时引入了 `cos` 项捕捉外部气候的周期与连续扰动，最后用极其高级的 `log(1+|x|)` （对数缓冲算子）来捕捉极高历史速度对当前拥堵的边际效应递减。这种具有第一性原理美感的方程在数学严谨性上彻底秒杀了传统深度学习黑盒。

### 🚀 2. 突破树模型的外推残疾（Extrapolation Robustness）
预测严苛未来的第一大痛点就在于“未见极值”。XGBoost 在预测到比历史训练最高峰还剧烈的拥堵时，其预测线会直接瘫平（树模型只能输出边缘常数叶子节点）。
而本系统的连续代数方程，利用多项式项或开口式的 $Hinge$ （铰链算子），能够**理直气壮地向外计算并预警极端的历史未见峰值**，绝非机械查表。

### 🛡️ 3. 终结分位数交叉（Quantile Crossing）的代数平滑拓扑
在进行区间预测估计时，基于树的模型极易出现“下界的叶子比上界的叶子还要高”的灾难（分位数交叉）。而本预测引擎的底层基于平滑正交基结构，使得参数空间曲面极其平顺，天然维持了卓越的分位数扩张与平行连续性（Heteroscedasticity），彻底终结了黑盒交叉乱象。

## 3. 共形预测（CQR）与非对称风险预警带：用风险度量代替点估计盲猜

这是本模型最能在顶级运筹与统计学界引发共鸣的理论底牌：**放弃均值信仰，建立严谨的统计数学抗风险高墙**。
交通实际调度中，指挥者不怕点预测有误差，怕的是黑天鹅事件突破了系统的忍控边界。我们创新性地引入了目前最前沿的统计界大杀器**共形分位数回归 (Conformalized Quantile Regression, CQR)**：

*   **绝对严谨的“零分布假设” (Distribution-Free)**：不需要像 ARIMA 或传统的置信区间（Confidence Interval）那样，去强行假设交通流残差服从完美的高斯正态分布。只需凭借历次预测与真实值的非符合性度量（Non-conformity score），在后处理校准集实现概率重布。
*   **极限的帕累托妥协战绩 (Pareto Optimal Boundary)**：
    *   在我们定义了目标覆盖防线为 **80%** (即 $\alpha=0.20$)、保留了 10% 即 `calib=0.10` 作为盲测校准集之下，我们在极大核种群的 3-seed 大规模核心并行实验中脱颖而出。
    *   **令人咋舌的实际平均覆盖率（PICP）：82.50%**（Seed 44 更是精准达到了 80.0%），这意味着区间不偏不倚地卡死了预期的预警概率底线！
    *   其归一化区间平均宽度（**PINAW**）被无情地收缩至死线内 **$\approx 0.30$** 附近极窄频段内。包得不仅准，而且包得极限锐利，避免了毫无业务指导意义的漫天大网。
    *   **区间综合惩罚得分 (Interval Score/IS)** 降至惊人的 **26.19**（同等量级 XGBoost 会直接因分位数崩盘炸出数十倍以上的天文数字）。
